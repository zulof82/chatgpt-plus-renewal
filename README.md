## ChatGPT Plus 续费失败怎么办

### 账号仍显示 Free

先不要马上重新购买。检查：

- 是否登录了正确邮箱；
- 是否使用了原来的登录方式；
- 订阅是否通过 App Store 购买；
- 账户设置里的计划状态是否已经更新；
- 是否需要退出后重新登录。

如果是移动端购买，OpenAI 建议在应用内使用“恢复购买”同步订阅；如果网页端和应用端显示不一致，也要确认两边登录的是同一个账号。

### 平台显示完成，但 ChatGPT 没有 Plus

保存以下信息，再联系客服：

- WildAI 订单编号；
- 付款时间和金额；
- ChatGPT 账户邮箱；
- ChatGPT 账户当前显示的计划；
- 订单页面截图；
- ChatGPT 账单或订阅状态截图。

不要只提供“打不开”三个字。账号邮箱、订单状态和具体错误信息越完整，客服越容易判断问题是在平台处理阶段，还是 OpenAI 账户侧没有同步。

### 付款成功后想退款

退款不能一概而论。WildAI 的退款说明显示，订单尚未完成、订阅未生效，或多月方案仍有未生效月份时，可以联系客服核实；如果订单已经完成履约，因选错套餐、误操作或购买后不想使用，通常不属于自动退款范围。

因此，下单前应确认四件事：

- 产品是不是 ChatGPT Plus；
- 账号是不是自己的目标账号；
- 选择的是 Plus 还是 Pro；
- 购买的是单月还是连续订阅。
